Project Big-Picture Overview

In plain English: Whenever a feedback ticket (a JSON text file) is uploaded to an AWS cloud storage bucket (S3), three automated microservices (AWS Lambda) wake up in milliseconds. They validate the ticket, categorize whether it is a bug, feature request, or complaint, score its priority, store it in a database (DynamoDB), archive a backup copy, and send live metrics to a real-time monitoring dashboard (Grafana) — engineered strictly to cost $0.00 / month.

Week 1: Cloud Foundations & IaC (Terraform)

  • Infrastructure as Code (IaC): Codified infrastructure in .tf files.
  • Amazon S3: Dual bucket architecture (raw drop-zone inbox + processed backup archive).
  • Amazon DynamoDB: Serverless NoSQL table with PAY_PER_REQUEST billing for $0 cost.
  • AWS IAM: Role-based access control with least privilege execution policies.

Week 2: Event-Driven Serverless ETL Pipeline

  • Extractor Lambda: Triggered by S3 ObjectCreated event $\rightarrow$ validates JSON schema.
  • Transformer Lambda: Heuristic keyword categorization and priority scoring $\rightarrow$ assigns UUID.
  • Loader Lambda: Writes record to DynamoDB and archives JSON copy to S3 partitioned by date.

Week 3: Containerization & AWS ECR (Docker)

  • Dockerized Lambdas: Built from official AWS Python base images; supports up to 10 GB payloads.
  • AWS ECR: Hosted container images in private Amazon Elastic Container Registry repositories.
  • Lessons Learned: Fixed multi-arch OCI manifest rejection by adding --platform linux/amd64 --provenance=false.

Week 4: CI/CD Automation (GitHub Actions)

  • CI Workflow: Flake8 linting, Pytest automated unit testing, and Terraform validation.
  • CD Workflow: Automated Docker buildx image push to ECR and terraform apply -auto-approve.
  • Remote S3 Backend: Unified state in S3 bucket so cloud runners and local machines share state.

Week 5: Observability Stack (Prometheus & Grafana)

  • Prometheus Pushgateway: Metrics collection bridge for short-lived serverless executions.
  • Prometheus: Scrapes Pushgateway and stores time-series metric streams.
  • Grafana: Real-time dashboard showing throughput, category donut charts, and severity bars.

Week 6: Automation Scripts & Final Polish

  • Traffic Simulator: simulate_traffic.ps1 sends realistic batches for live interview demos.
  • Teardown Automation: teardown.ps1 destroys all cloud resources with zero-spend guarantee.
